# knowledge/

Aquí van, **solo en la máquina corporativa**, los archivos de conocimiento
saneados (arquitectura de la aplicación y conocimiento operativo de los ADRs).
Todo lo que pongas aquí salvo este README está en `.gitignore`.

`foundry-setup --knowledge-dir knowledge` los sube al agente de Foundry como
*file search*. Antes de subirlos, confirma que no contienen secretos,
API keys, números de cuenta, correos ni nombres de personas.
